# Local SQLite database

The local test database is created at `data/triptech.db`.

It is intentionally ignored by git so each developer can test with their own
local catalogue data.

Useful local endpoints while the Next app is running:

- `GET /api/products`
- `POST /api/products`
- `PUT /api/products/:id`
- `DELETE /api/products/:id`
- `GET /api/quote-requests`
- `POST /api/quote-requests`
